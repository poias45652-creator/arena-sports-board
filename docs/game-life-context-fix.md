# 棒球關鍵局面與短約修正

## 原因與變更

- 原本投手在指定局數的第一個打席就觸發決策，因此精華模式常見 0 出局、壘上無人。改為從實際逐打席模擬中加權選取關鍵打席：壘上有人、得點圈、滿壘及後段接近比分提高入選機會，保留無人上壘的正常局面。
- 預覽使用隔離的亂數狀態，原本模擬照同一個亂數序列前進到選定打席。沒有增加跑者、強制安打、改寫比分或額外抽取賽果。玩家作出選擇後，後續模擬沿用新的局面。
- 前台顯示最近 4 個打席的打序、結果、得分、出局與壘包；存檔保留最近 6 個打席。舊存檔缺少紀錄仍可接續。
- 修正守備封殺原本可能移除未被迫進壘跑者、或覆蓋一壘跑者的問題。沒有封殺條件時改抓打者一壘出局，選項文案隨局面改變。
- 原本所有報價都顯示改簽一年短約。現在僅 2–4 年報價可縮短；一年約顯示已是短約。引擎同時拒絕無效縮短，不扣薪、不消耗談判次數、不改亂數。有效縮短仍為年薪 -10%，保留市場與存檔結果。
