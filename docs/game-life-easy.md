# 輕鬆玩

預設介面依序呈現「選方向、做選擇、打關鍵戰、看回顧」。開局先選球類、姓名與位置，其他設定放入可展開的自訂區塊。

每季四張方向卡一次安排既有目標、訓練強度與精華訓練；訓練與隨機結果全部沿用引擎。生涯地圖、故事後續、場上選擇、合約、照護與重大動畫繼續保留。詳細戰績和設定可以展開，也能隨時切回進階操作。

| 方向 | 本季目標 | 訓練 |
| --- | --- | --- |
| 衝刺成長 | 綜合能力增加 2 點 | 位置主要專項，正常特訓 |
| 站穩位置 | 有出賽且信任達 65 | 位置第二專項，穩健打底 |
| 挑戰前三 | 例行賽前三名 | 位置第三專項，極限突破 |
| 調整身心 | 季末健康 65、心情 55 | 休息復健 |

操作模式偏好獨立存於 `xingzhun-play-mode-v1`；切換介面不寫入存檔、不消耗隨機數、不改篇章長度。點擊方向卡才將節奏設為精華並安排剩餘訓練。已開始訓練的賽季保留原目標與完成次數；重大健康條件優先進入照護。原有完整生涯仍然是完整生涯，新建短篇保留八季長度。

驗證：方向卡與逐項操作的完整引擎狀態一致、重複操作不生效、途中訓練接續、健康門檻攔截、介面切換及呈現唯讀、三球類八季流程與舊存檔回讀。
