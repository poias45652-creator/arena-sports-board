## 網站公式

有足夠且已實際套用的近期 xG 時，取星準原式的主勝、和局、客勝三者最大值。沒有足夠 xG 時，兩隊須各有至少 5 場可驗證射正，主客 ID、開賽時間、聯賽及年度賽程均須對上。資料不足的場次不列精選。缺 xG 分支的最高機率達 0.70 才取代原比分分布，三向並列第一時不列精選。每場在開賽前保存，結算採各場最後一筆有效快照。

每隊進球期望值為 `exp(Σ βᵢ (xᵢ−μᵢ)/σᵢ)`。欄位依序為常數、聯賽主／客平均進球的對數、主客指標、相對 Elo、己隊進球、對手失球、己隊射正、對手被射正。末四項依聯賽均值正規化。取 365 天內最多 20 場，權重為 `exp(−天數/90)`，加入 5 場聯賽平均作平滑。Elo 從前一曆年 1 月 1 日起算，初始 1500、K=20、主場 60 點、跨年保留 85% 差值。凍結進球率後，以兩隊 Poisson 分布求 90 分鐘比分，0 至 20 球網格重新正規化。係數見 `data/football/shot-selection-v1.json`。本版沒有使用賠率、未經驗證的傷停名單或估造的 xG。

## 逐場核對

解壓同目錄的 `fixtures.csv.gz`。舊版取 `old_home/draw/away`；新精選在 `old_path=xg` 時沿用舊式，其餘取 `shot_home/draw/away`，最大值達 0.70 即列精選。未入選的場次沿用原方向。每一列皆有 ESPN 賽事 ID，可核對 `https://www.espn.com/soccer/match/_/gameId/{espn_id}`。原始年度來源為 `https://site.api.espn.com/apis/site/v2/sports/soccer/{league}/scoreboard?dates={year}&limit=1000`。同日完場、改判、已知中止與跨日續賽場次均不供模型學習。下一輪依網站實際封存、結算的精選檢驗。
