# MT 共用試玩

固定使用已由站主確認不可提領或兌現的測試帳號 `dvp0322`。入口為 `/mt-trial`，與會員／管理員登入隔離。

## 啟用設定

在部署服務的私密環境變數設定：

- `OFA_MT_TRIAL_ENABLED=true`
- `OFA_MT_TRIAL_PASSWORD`：dvp0322 的測試帳號密碼。只填入部署平台的秘密設定，勿提交到版本庫或公開前端。

預設不啟用；缺少密碼時顯示未設定，不會假裝登入成功，也不會使用管理員 Cookie 代替授權。

## 連線行為

伺服器獨立向 OFA 驗證固定帳號，再取得 MT 專用遊戲網址。OFA token 只留在伺服器記憶體，不寫入會員 session，也不傳給訪客。訪客不會因此登入會員或管理後台。

有效的遊戲網址暫存最多五分鐘；同一執行個體的同時請求共用一次登入。OFA 授權即將到期時，下次連接會重新驗證；程序重啟後也會重新驗證。上游失敗會回退 30 秒，且不回傳原始錯誤／帳密。

這不是永久登入保證。MT 若不允許同帳號多裝置連線，訪客可能互相中斷，且會共用遊戲進度與點數。需要多人獨立試玩時，應由遊戲商提供獨立試玩 session。

MT 是否允許嵌入仍待實測；頁面提供另開視窗入口。重新連接會優先使用仍有效的暫存網址，避免每次操作都重發登入而踢掉其他訪客。

## 驗證

`node --test tests/mt-trial.test.mjs`

驗證關閉／缺少設定不連線、同源 POST、固定帳號身分、同時請求去重、到期重登、錯誤遮蔽及遊戲網址白名單。測試使用虛構授權，不登入外部平台。
