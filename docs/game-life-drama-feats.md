# 感情風暴、單場稱號與突然開竅

感情事件從 19 歲且已交往後出現。13 段故事包含伴侶背叛、自己的曖昧／外遇、前任、流言、失約、夢想衝突、驚喜探班、低潮陪伴，以及揭穿、修復、分手復原、重逢與前任婚禮。每段三個選項，心情變化為 -38 至 +20，仍受 0–100 邊界限制。

- 第一次感情考驗取代原本的遠距磨合事件，其餘婚育與孩子養成里程碑保留。
- 外遇揭穿與復原等後續優先使用下一季原有故事格，既有到期事件仍優先；不增加短篇的八季上限或每季事件配額。
- `family.stage` 保留歷史婚育里程碑，`romance.bond` 記錄現在關係。分手不刪除孩子，仍可培養、引退及傳承。
- 關係選擇與心情差值由引擎結算；動畫與重播不改變遊戲狀態。

12 個單場稱號分屬三種球類，各 4 個。以俱樂部比賽完成時的個人實績判定，包括三振、雙響砲、猛打、守備、帽子戲法、助攻、零封、30 分、大三元與籃板。每個稱號在這一位球員的生涯持續提供專項加成，同名不疊加，各專項總加成最多 +8、能力最高 99。加成透過能力計算進入實際決策、模擬與雷達圖，不直接修改基礎屬性，不繼承到孩子。

突然開竅在第一次進入一場可操作的關鍵時刻時判定，機率 0.3%。種子與比賽識別碼決定結果，同一場只判定一次；讀檔、再次顯示與重播不重抽。發動後剩餘比賽的專項 +25，臨場最高 99，終場清除，不改永久能力。提示、HUD、雷達與成功率皆顯示／使用此狀態，並播放專屬動畫。

舊存檔沒有新欄位時仍可讀取，不會補發歷史稱號，不消耗隨機數，也不改存檔目錄或儲存鍵。既有尚未完成的 `family-distance` 選項可照常結算。

驗證：`node --test tests/game-life-*.test.mjs`，以及 `npm run build`。新增測試涵蓋全部感情選項、後續條件、孩子保留、心情實際變化、稱號加成與重複結算、機率分布、開竅到期、動畫唯讀及存檔驗證。
