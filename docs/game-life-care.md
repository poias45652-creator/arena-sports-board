# 星準遊戲人生：手術與心理照護

## 行為

- 在既有健康、體力、士氣、默契之外新增 0–100 的心情。新生涯初始 62–84；舊存檔補 70，不改亂數狀態。
- 心情獨立影響事件成功率、臨場能力與訓練效率。正常／極限訓練分別消耗 2／5；休息復健回復 5。故事、比賽與傷勢會連動改變心情。
- 健康 ≤20 叫停一般操作，進入傷勢檢查與手術事件。四種手術支援安排，其中三種免費。完成 2–3 段復健後，健康至少 55；本季保護性出場倍率為 45–75%。
- 心情 ≤25 持續 3 個有效行動，觸發專業心理評估劇情；接受評估後進入憂鬱症照護與 2–3 段心理治療、支持或休養。心情 ≤10 時立即安排評估，但單次低落不會直接被診斷為憂鬱症。
- 完成心理照護後心情至少 45，狀態為「心理追蹤中」，不是一次點擊治癒。下一季心情 ≥55 才在追蹤評估後回到穩定狀態。
- 每季另可安排一次免費心理輔導，回復心情 12、士氣 3、體力 8，無法重複刷取。
- 兩種危機並存時，先處理手術，再評估仍持續的心情危機。照護暫存於同一份存檔，不改動原事件、合約或對局階段；完成後接續。
- 精華訓練途中觸發危機時立刻停止剩餘訓練，完成照護後繼續剩餘次數。照護需求會先於低健康造成的直接退休。

## 文案依據

心理劇情區分一般情緒低落與經專業評估的憂鬱症，包含持續低落、睡眠與興趣變化，以及心理治療與支持。僅以遊戲分數控制劇情，不把分數當成現實診斷標準。參考 WHO 的憂鬱症說明：
https://www.who.int/en/news-room/fact-sheets/detail/depression
