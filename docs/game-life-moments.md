# 重大時刻動畫

`moments.js` 在成功的玩家操作前後比較唯讀快照，呈現實際發生的醫療暫停、手術、心理評估／照護、復健完成、重大傷勢、聯賽／國家隊冠軍、簽約／租借、國家隊徵召與生涯結束。

- 引擎先完成結果並存檔，畫面再播放；動畫不擲骰、不發放獎勵、不推進回合。
- 同一次操作的多件事件合併成一個畫面，照護優先，其他結果列在下方。
- 自動播放 3.4 秒；跳過、回到遊戲與 Escape 均可立即關閉。關閉取消計時器並恢復焦點。
- 重播使用目前角色本次遊玩中最近的重大結果，持續顯示直到手動關閉。切換／匯入角色清除重播內容。
- `xingzhun-motion-v1` 只儲存動畫偏好；生涯存檔格式及原本的存檔鍵不變。載入舊存檔不重播過去事件。
- SVG 與 CSS 動畫由本站提供，不載入第三方影片，無自動音效、快速閃光；遵守減少動態效果設定。

驗證：`game-life-moments.test.mjs` 涵蓋實際醫療流程、三球類八季流程、同時多事件、租借／合約文字、重播不變更狀態、匯入字串跳脫、跳過／Escape／計時器清理。原有照護、存檔與比賽測試保留，更新 UI 測試的原生 dialog 模擬以驗證動畫和照護畫面同時存在。
