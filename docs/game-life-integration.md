# 星準遊戲人生站內整合

- `/game-life` 直接提供完整的星準體育人生模擬器 HTML，建置時預先產生。
- `public/game-life/` 包含 v11 的三球類引擎、事件、結局、存檔、介面與樣式。11 支 JavaScript 與原本已發布的來源 `ec6bde30ba466c172e2e7c7610eba4f66fab8725` 逐位元相同。
- 共用網站既有的 8 個星準品牌圖片，沒有 iframe、外站跳轉或 ChatGPT 執行需求。
- 登入頁「遊戲人生」改為同頁開啟 `/game-life`；金色漸層、遊戲圖示與 42px 點擊高度。小螢幕隱藏裝飾圖示，保留完整文字。
- 遊戲提供返回星準連結。瀏覽器存檔使用既有 `xingzhun-*` 鍵，與帳號、賽事資料及認證分離。原本另一網域的存檔需要使用遊戲既有匯出／匯入功能轉移。

## 驗證

- Next.js 正式版建置成功，`/game-life` 為靜態路由。
- 正式模式 HTTP：`/login`、`/game-life` 皆為 200；13 個直接引用的腳本、樣式及圖片全部同站載入成功，返回連結與同頁入口正確。
- 原遊戲測試在搬移後的程式執行；UI 測試的資源定位改成取路徑檔名，以適應 `/game-life/*.js?v=1`。82 個功能測試通過，涵蓋三球類、事件、存檔、投手專項與健康／士氣。
- 一個既有大量種子統計測試仍未通過：540 次完整生涯看到 589 種事件，舊斷言預期看到全部 600 種。此次所有遊戲引擎檔案保持相同，未為符合此統計斷言而調整遊戲內容或抽選機率。
