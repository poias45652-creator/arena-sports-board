# 球場選擇動畫

手動擊球、投球、守備、足球攻防與籃球攻防完成判定後，播放約 1.9 秒的球場動作。三種球類各有場地、球員動作與球的移動；結果、隊名與比分取自同一次實際選擇。

精華節奏會模擬剩餘比賽，因此動畫使用 `highlight.before` 和 `highlight.after` 的決策當下比分，不使用可能已更新的終場比分。棒球雙殺依選擇前壘包與出局數區分；保送、三振與犧牲推進不當作安打。足球保留球權不顯示進球，籃球犯規使用實際罰球得分。

每次選擇只判定與存檔一次；動畫、略過與重播均不調用遊戲引擎。畫面偏好獨立存於 `xingzhun-plays-v1`，舊存檔不增加必填欄位。自動完成比賽、無效選項或先被照護攔截的操作不會假造手動動作。若同次操作觸發重大事件，球場短動畫結束後接續重大事件動畫。切換球員會取消全部待播動畫。

可隨時略過、按 Escape、關閉球場動畫，或在比賽結果下方重播。重播停留到手動關閉；減少動態效果偏好改用靜態結果畫面。

## 2026-10-21 戰術轉播改版

- 以原創 SVG 俯視球場替代側面線條人物，三種球類各自呈現跑位與球路。
- `stadium.js` 是純呈現層；球員背號與能力雷達取自既有生涯，結果字幕和比分取自實際判定。
- 總演出改為 2.6 秒：跑位、出手、結果；仍可略過／重播，接續重大事件不遺漏。
- `feedback.js` 使用獨立特效節點呈現按壓波紋，最多四組；不呼叫遊戲方法、不延後 onclick，也不寫入生涯存檔。僅獨立保存觸擊偏好 `xingzhun-touch-v1`。
- 視覺規格、參考觀察與響應式取捨見 `game-life-design/DESIGN.md`。
