# 星準遊戲人生：短篇、目標與存檔保護

## 行為

- 新開局預設八季短篇（16–23 歲），保留完整生涯選項。八季結算是篇章封存，不把角色設定成提早退休；可延續同一球員，年齡、合約、能力、比賽與亂數進度都保留。舊存檔沒有 `journey` 欄位時維持原本生涯長度。
- 四種自選賽季目標：能力成長、教練信任、例行賽前三、健康與心情。第一次訓練後鎖定，完整賽季及國家隊流程結束才結算獎勵，同一季不可重複領取。
- 四個目標故事與一段隔年後續加入原事件池。首次選擇目標會優先遇到對應故事，到期支線優先；不增加強制回合。
- 新增轉播／體育日報風格、依真實履歷繪製的生涯地圖與能力曲線、目標收藏及選擇後的數值增減。詳細數據收合，手機先顯示玩法再顯示球員資料。

## 存檔

- 維持既有 `xingzhun-saves-v1`、`xingzhun-save-*`、`triple-*` 儲存鍵和 v1/v3 讀取流程。
- 新開局與匯入都新增獨立槽，不移除同球類舊槽。舊 `replaceSport` 呼叫也改為新增，避免快取呼叫仍執行清除。
- 每個既有槽首次覆寫前保留原始 JSON；首次替換舊 `triple-*` 指標也保留原始 JSON。備份可由讀檔清單另建副本，原槽不受影響。
- 寫入失敗會回復已修改的鍵；毀損目錄不被默默覆蓋。匯入必須驗證與寫入成功才切換目前角色。
- 此版本不連接或修改帳號、認證、雲端資料庫，也不清除結局及事件圖鑑。
