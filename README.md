# YJ體育分析｜第 91 版 Render 完整原始碼（登入／登出與管理員後台入口修正）

這份完整專案包含 Render 部署修正、最新文字修改，以及補回的首頁登出按鈕、管理員後台入口與後台登出按鈕。

## 登入與登出

- 首頁右上角「登出」按鈕已補回，點擊後會清除目前登入工作階段與 Cookie，成功後回到 `/login`。
- 登出失敗會顯示重試訊息，不會假裝已登出。
- 登入頁保留原有帳號、密碼、建立帳號與首次管理員設定。可直接開啟網站的 `/login`。
- 若瀏覽器仍保有有效登入狀態，開啟首頁會顯示網站內容；未登入者則會導向登入頁。

## 管理員後台

- 使用既有管理員帳號登入，首頁右上角會顯示「管理後台」，點擊前往 `/admin`。
- 管理後台保留原有工具，右上角可「返回前台」或「登出」。
- 伺服器會確認管理員角色；一般會員不顯示入口，直接輸入後台網址也無法讀取後台內容。
- 不需重建帳號或資料庫；既有管理員權限保持不變。

## 上傳方式

1. 解壓縮，進入 `arena-sports-board` 資料夾。
2. 將資料夾內的檔案與子資料夾上傳至 GitHub 儲存庫根目錄，覆蓋現有同名檔案。`package.json` 必須位於根目錄，並一併上傳 `.npmrc` 等設定檔。
3. Render 保持 Node.js 24，Build Command 為 `npm ci --ignore-scripts && npm run build`，Start Command 為 `npm start`，Health Check Path 為 `/api/health`。
4. 保留既有環境變數及資料庫，重新部署最新提交。

本包補回缺少的 `pg` 套件，並修復 Next.js 建置、PostgreSQL、登入身分與歷史檔案讀取的 Render 相容設定。已通過正式建置、TypeScript 檢查、本機正式伺服器登入頁與導向檢查，以及使用隔離模擬工作階段的管理員入口、會員阻擋、管理 API 權限與登出後撤銷登入狀態檢查。本次未改動線上部署、會員資料或環境變數。
