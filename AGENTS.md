# User-facing language

The owner requires Traditional Chinese (Taiwan) for all current and future user-facing interface copy, match descriptions, event details and play-by-play updates.

- Apply localization to newly fetched records, not only to saved examples or the current match.
- Translate action wording and use verified Chinese team/player aliases where available. Preserve source identities, scores, event ordering, substitution direction and decisions; never invent a name translation or match event.
- Do not display untranslated source prose as the default description. If an unfamiliar phrase cannot be translated reliably, keep its original available under a clearly labeled Chinese disclosure instead of claiming a guessed translation.
- Add regression coverage using the actual reported source text when correcting localization.
